# BulkWaterDiffuse (Physics Capstone QUT PVB304)
Diffusion of water is a random process described best by Brownian
motion. Water is known to diffuse isotropically. When there is
damage within articular cartilage increases in ansiotropic diffusion
occurs. This project is an investigation into how to simuluate
this phenomena and confirm the expected isotropic and ansiotropic
diffusion of water in a range of scenarios.

The main analysis to determine ansiotropy is through the diffusion tensor generated by
the simulations. See the results section for more info.

## Initial Conditions
- Number of steps = `500`
> P.S. All values are roughly to scale to idealised radial collagen fibers.
- Diffusion Coefficient = `3.75*10**4 nm`
- Simulation time step = `2.67*10**(-8) s`
- Collagen network lattice spacing = `1 (~666 µm)`
- Collagen network fiber radius = `0.3 (~200 µm)`

## Simulations Run
1. 250x3x1 [100, ..., 100k] equidistant water particle counts with initial conditions.
2. 250x3x5 [100, ..., 100k] equidistant water particle counts with reduced collagen radius by `-25%` per simulation (100, 75, ..., 0).
